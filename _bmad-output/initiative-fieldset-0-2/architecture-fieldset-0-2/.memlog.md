- (constraint) Inputs: research-artemis-usage.md (consumer flows, sizes, bench), party memlog (6 outcomes), session conversation. Artemis migration out of scope; artemis flows are the acceptance evidence.
- (decision) Paradigm: plain-data model + lens-style generated handles + dirty-mask notifications. Model struct stays pure data (repr(C)/serde/IPC untouched); crate adds items beside it, never inside it. Prevents: anything embedded in the model, tracker inside IPC structs.
- (decision) AD: writes only through generated XMut<'a> handles holding &'a mut subtree + &'a mut Changes + base leaf. One live handle per subtree (enforced by &mut). Prevents: writes that bypass tracking; two writers of one subtree.
- (decision) AD: handle API is methods at every level: nested field -> child XMut<'_>; leaf field -> Field<'_, T> with get/set/set_if_changed/update; model() -> &Subtree. No Deref, no macros, no path types, no eager handle tree. Prevents: eager 4.8KB handle trees, Cell mask, two read syntaxes.
- (decision) AD: Changes<R: Fields> is a COUNT-bit mask only. No capacity param, no list, no overflow. set never fails. drain() and iter() scan in declaration (leaf) order; mark_all sets all; clear; len/is_empty. const fn new for statics. Prevents: per-batch allocation/copies, modification-order dependencies, overflow policies.
- (decision) AD: notification currency is the runtime path enum XPath: nested unit variants, repr(u8), Copy/Eq/Debug, leaf()/from_leaf(u16) via a const table, generated Option projections per nested field (path.base() -> Option<BasePath>). No values in events in 0.2. Prevents: largest-field inflation, stale valued events.
- (decision) AD: policy and routing live in the host loop, not the crate: drain after each controller call; reactors receive (XPath, &Subtree) and never &mut; no Gate, no Origin. Prevents: per-write hooks, origin fields in events, reactors mutating during a drain.
- (decision) AD: Fields trait is the composition seam: COUNT, type Path, type Mut<'a> (GAT); nested composition via <Sub as Fields>::COUNT; no module-level consts; generated code uses ::fieldset:: paths and fully-qualified trait calls; generated items inherit the struct's visibility. Prevents: cross-module breakage, name pollution, trait-not-in-scope errors.
- (decision) AD: indexed fields: #[fields(indexed)] on [T; N] gives handle method f(i: Index<N>) -> child handle or Field, path variant F(Index<N>, TPath) or F(Index<N>), leaf = base + i*T::COUNT + inner. Index<N> is a bounded newtype; from_leaf decodes by division. Prevents: whole-array events; per-element table entries.
- (decision) AD: enums with payloads are leaves (whole-value set); flatten idiom (tag + sibling payload structs) is the recommended model shape; nested enum editing and Option<T> prisms are out of 0.2. Prevents: events valid only under an active variant.
- (decision) AD: leaf types must be Copy in 0.2 (get/set by value); set_if_changed additionally requires PartialEq; set has no bound beyond Copy. Prevents: drop bookkeeping in the mask design; silent PartialEq requirement.
- (decision) AD: stable Rust, no_std, no alloc, no feature gates; every generated type nameable; derive emits syn::Error with spans, never panics; derive input is structs with named fields only. Prevents: nightly requirement, panicking derives.
- (decision) AD: derive #[derive(Fields)] with field attributes #[fields(nested)], #[fields(skip)], #[fields(indexed)]; generated items XPath, XMut<'a>, impl Fields for X. Generated name collisions with user fields are a spanned compile error. Prevents: attribute sprawl, silent shadowing.
- (decision) AD: 0.2 is a clean break: OptFieldSet/BitFieldSet/PerfFieldSet, IntoIterator for the struct, *_VARIANCE consts, FieldSetter closures all removed; version 0.2.0 for both crates, published macro-first; runtime depends on macro by path+version in one workspace with one lockfile. Prevents: two lockfiles, testing against the published macro.

Prevents: regressions nobody measures.
